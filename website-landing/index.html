Dashboard

Overview komprehensif semua aktivitas maintenance

Fitur Utama

  • Statistik real-time downtime
  • PM & PdM completion rate
  • Work order status tracking
  • Machine & user statistics
  • Top machines dengan downtime tertinggi
  • Downtime trend per hari

Cara Menggunakan

  1. Pilih data source (Downtime ERP2/ERP/Downtime)
  2. Filter berdasarkan bulan dan tahun
  3. Lihat statistik di kartu-kartu dashboard
  4. Scroll untuk melihat chart dan top lists
  5. Klik detail untuk informasi lebih lanjut

Tips & Trik

💡 Filter Persistence: Filter yang dipilih akan tersimpan di session, jadi tidak perlu set ulang setiap kali masuk.

💡 Data Source: Pilih data source sesuai kebutuhan - ERP2 untuk data terbaru, ERP untuk data legacy.

Sistem Alert Otomatis

Sistem akan otomatis mengirim email alert ke managers untuk kondisi-kondisi penting:

Sparepart Low Stock Alert

Alert otomatis dikirim jika:

  • Stock sparepart di bawah minimum stock
  • Terjadi saat create/update sparepart
  • Email dikirim ke managers yang dikonfigurasi

Setting minimum stock di form create/edit sparepart

Predictive Red Status Alert

Alert otomatis dikirim jika:

  • Inputan Predictive Maintenance memiliki status merah (critical)
  • Terjadi saat input/update measurement value
  • Email dikirim ke managers yang dikonfigurasi

Status: 🟢 Normal | 🟡 Warning | 🟠 Caution | 🔴 Critical (Alert)

Setting Email Managers

Konfigurasi recipients untuk alert (sama dengan Downtime Alert):

Edit file .env:

DOWNTIME_ALERT_ENABLED=true

DOWNTIME_ALERT_ROLES=manager,general_manager,coordinator

Bisa juga set via email spesifik atau user IDs di config file

Location Management

Hierarki lokasi: Plant → Process → Line → Room

Struktur Hierarki

Plant - Level tertinggi (contoh: Plant A, Plant B)
Process - Proses produksi di dalam plant
Line - Line produksi di dalam process
Room - Ruangan di dalam line

Prosedur Penggunaan

  1. Buat Plant terlebih dahulu (jika belum ada)
  2. Buat Process di dalam plant
  3. Buat Line di dalam process
  4. Buat Room di dalam line (optional)
  5. Gunakan Import dari Room ERP untuk sync data
  6. Setelah setup, mesin bisa di-assign ke location

Akses & Permission

Role yang bisa akses: Coordinator, Assistant Manager, Manager, General Manager

Fitur Import: Hanya untuk role Coordinator ke atas untuk sinkronisasi data dari ERP system.

Downtime Management

Tracking lengkap breakdown dengan Problem, Reason, Action, dan Work Order

Master Data

Problems: Masalah yang terjadi (contoh: Motor Failure, Sensor Error)
Reasons: Alasan terjadinya masalah (contoh: Overload, Wear & Tear)
Actions: Tindakan yang dilakukan (contoh: Replace Motor, Calibrate Sensor)
Parts: Spare part yang digunakan untuk repair

Work Orders

Sistem work order untuk tracking repair progress

  • • Status: Pending, In Progress, Completed
  • • Priority: Low, Medium, High, Critical
  • • Assignment ke mekanik/team
  • • Photo documentation
  • • Time tracking

Prosedur Input Downtime

1. Pilih Mesin

Cari mesin dengan ID atau scan barcode. Sistem akan auto-fill location.

2. Input Waktu

Masukkan stop production, response mechanic, dan start production time.

3. Pilih Problem

Pilih problem dari dropdown (filter by system).

4. Pilih Reason & Action

Pilih reason dan action yang sesuai dengan problem.

5. Assign Mekanik

Pilih mekanik yang menangani. Leader & Coordinator auto-fill.

6. Input Parts (Optional)

Tambahkan spare parts yang digunakan beserta quantity.

Downtime Alert System

Sistem akan otomatis mengirim notifikasi email ke managers jika:

  • Duration downtime > 60 menit (configurable)
  • Problem critical (Motor Failure, Safety Issue, dll)
  • Machine critical tertentu
Setting Email Managers

Edit file .env atau config/downtime_alert.php:

DOWNTIME_ALERT_ENABLED=true

DOWNTIME_ALERT_ROLES=manager,general_manager,coordinator

DOWNTIME_ALERT_DURATION_THRESHOLD=60

Bisa juga set via email spesifik atau user IDs

Production Tracking

Tracking produksi per jam dan per hari untuk perhitungan OEE

Production Hourly

Input produksi per jam (0-23) untuk setiap line dan process

  • • Total Production: Jumlah unit yang diproduksi
  • • Target per Hour: Target produksi per jam
  • • Grade B & C: Defect yang terjadi
  • • Notes: Catatan khusus (contoh: "istirahat")

Production Daily

Summary produksi per hari dengan grade breakdown

  • • Grade A: Produk baik (dari Production Hourly)
  • • Grade B & C: Defect per hari
  • • Production Hours: Jam operasi (start - end - break)
  • • Production Downtime: Downtime non-machine (process, quality, material)

Perhitungan OEE

Availability

= (Operating Time / Planned Time) × 100%

Performance

= (Actual Output / Target Output) × 100%

Quality

= (Good Units / Total Units) × 100%

OEE = Availability × Performance × Quality / 10000

Preventive Maintenance

Sistem PM lengkap: Scheduling → Controlling → Monitoring → Updating → Reporting

Scheduling

Jadwal PM

Controlling

Kontrol eksekusi

Monitoring

Monitor progress

Updating

Update schedule

Reporting

Laporan PM

Workflow PM

1
Scheduling: Buat jadwal PM dengan interval (daily, weekly, monthly). Assign PIC (Person In Charge).
2
Controlling: Eksekusi PM sesuai jadwal. Input hasil maintenance, foto, dan catatan.
3
Monitoring: Monitor completion rate, overdue schedules, dan performance PIC.
4
Updating: Update jadwal jika perlu reschedule atau ubah interval.
5
Reporting: Generate laporan PM completion, trend, dan analisis.

Predictive Maintenance

Maintenance berbasis standar dengan pengukuran nilai untuk prediksi breakdown

Standards Management

Buat standar pengukuran untuk setiap maintenance point

  • • Link ke Machine Type & Maintenance Point
  • • Set nilai min, max, dan target
  • • Upload foto standar
  • • Multiple variants untuk kondisi berbeda
  • • Status: Active/Inactive

Measurement Process

  1. Schedule PdM berdasarkan interval
  2. Eksekusi measurement di Controlling
  3. Input nilai measurement
  4. Sistem compare dengan standard
  5. Alert jika nilai di luar range
  6. Track trend untuk prediksi

Tips Predictive Maintenance
